# Mundo Móvil - Catálogo V3

Prototipo de catálogo con ficha de compra para Samsung Galaxy A17.

## Qué agrega esta versión
- Samsung Galaxy A17 128 GB / 4 GB RAM / Gris con foto real.
- Precio efectivo: $380.000.
- Transferencia: $399.000.
- 6 cuotas de $85.000.
- Modal de opciones de compra.
- Retiro: con stock muestra "Retiro mañana"; sin stock puede mostrar "Retiro mañana a partir de las 17 hs".
- Botón "Continuar por WhatsApp" que arma el mensaje de reserva.

## WhatsApp
En `app.js`, completar `WHATSAPP_NUMBER` con el número real de Mundo Móvil, solo números y con código de país, por ejemplo: `54911XXXXXXXX`.

## Futuro
La estructura está preparada para que después los datos vengan desde Google Sheets.
